
# Increasing Sequence

A C#/.NET console application that finds the longest contiguous strictly increasing sequence in a series of integers.

## Solution Structure

- `src/IncreasingSequence.Core` — Core algorithm and business logic.
- `src/IncreasingSequence.Console` — Console application.
- `tests/IncreasingSequence.Tests` — Automated unit tests.

## Prerequisites

- .NET 10 SDK

## Build

```bash
dotnet build
```

## Run Tests

```bash
dotnet test
```

Further implementation and usage instructions will be added as development progresses.
